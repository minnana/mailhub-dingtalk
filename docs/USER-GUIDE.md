# 公司邮箱员工使用手册

公司邮箱把多个邮箱放在钉钉中的一个入口里。每位员工有自己的账号和已绑定邮箱；首次使用需要授权邮箱，以后从钉钉打开时会重新确认当前员工身份。

本手册对应 Mailhub 钉钉应用 0.1.0、Nextcloud 34.0.5 和 Mail 5.12.5 的当前实现。具体开放时间和已验收的设备以公司管理员通知为准；这份手册本身不代表已完成真实免登、收发和提醒验收。

## 先找到你要做的事

| 想做什么 | 从哪里开始 |
| --- | --- |
| 第一次使用公司邮箱 | 钉钉 → 公司工作台 → 公司邮箱，按第 1、2 节操作。 |
| 用普通浏览器登录 | 先在钉钉内进入“个人设置 → 网页登录”，设置密码并收藏专属入口。 |
| 再加一个邮箱 | 在 Mail 中添加另一个账号，每个邮箱分别授权。 |
| 忘记网页登录密码 | 从钉钉重新进入“网页登录”，再次确认身份后设置新密码。 |
| 收信、发信或提醒异常 | 看第 6 节；提供发生时间和错误文字，不提供密码。 |

日常使用要区分三套信息：钉钉账号用于确认员工身份，邮箱密码/授权码用于连接原邮箱，Mailhub 网页登录密码用于普通浏览器。它们不能互相替代。

## 1. 第一次打开

1. 登录自己的钉钉账号，并切换到公司所在的组织。
2. 在工作台找到管理员发布的“公司邮箱”。应用名称如果被公司修改，以实际名称为准。
3. 打开后先准备安全登录、退出这个页面之前使用的邮箱会话，再确认当前钉钉身份。成功后进入邮箱页面。
4. 首次进入时，按页面提示添加自己的邮箱账号。

不需要为公司邮箱另外注册账号，也不需要向同事索取一套公共登录密码。不要把管理员账号当作全公司共用账号。

如果工作台中没有入口，请联系管理员检查应用是否已发布给你。普通浏览器不会自动取得钉钉身份；可以按下节设置独立网页登录密码。

### 不打开钉钉，也能用浏览器登录

1. 先从钉钉工作台进入邮箱，点击右上角头像 → 设置 → **网页登录**，打开“查看网页登录账号 / 设置密码”。
2. 页面显示你已有账号的网页用户名，可一键复制。使用“打开专属网页登录入口”，在普通浏览器中收藏该地址；以后登录页会自动填写用户名。
3. 在钉钉内输入两遍新密码（12–128 个字符），点击“确认身份并保存密码”。系统会再次核对当前钉钉身份。
4. 保存后，此账号在各设备上的旧会话会退出。以后用浏览器打开收藏的专属入口，输入刚设置的密码即可；仍然可以从钉钉免登。

这是同一个账号，不会新增第二个邮箱空间，也不用重新绑定邮箱。网页登录密码与钉钉密码、原邮箱密码或授权码各自独立。密码由你设置，系统不会显示旧密码或给全员分配同一个初始密码。

忘记网页登录密码时，从钉钉进入“网页登录”重新设置。若钉钉账号已不可用，请联系管理员；不要新建账号来代替原账号。公共电脑使用后退出登录；若浏览器已经登录了另一个人，先退出再使用自己的专属入口，链接本身不会切换已登录身份。

网页用户名是系统生成的一串字符，较长是正常的，不是邮箱地址、钉钉手机号或昵称。优先使用专属收藏入口；不要自行缩短或改写用户名。专属链接本身不能免密登录，也不会把钉钉的登录状态自动传给另一个浏览器。

设置页长时间未操作、重复点击保存或验证失败时，重新打开该页后再试。保存成功导致其他设备退出是预期行为，重新从钉钉进入或输入新密码即可；原邮箱的密码和授权码不会因此改变。

## 2. 第一次绑定邮箱

准备完整邮箱地址，以及邮箱服务商要求的密码或“客户端授权码”。授权码也可能叫“客户端专用密码”“第三方客户端安全密码”，它和钉钉密码无关。

1. 在 Mail 中选择添加邮箱账号；具体按钮名称以页面语言为准。
2. 填写自己的姓名、完整邮箱地址和邮箱授权信息。
3. 如果自动配置没有成功，使用手动配置，填写管理员提供的收信和发信设置。
4. 保存后等待首次同步。邮件较多时，首次显示完整列表需要时间。
5. 发一封测试邮件，再请同事回复，分别确认发信和收信正常。

手动配置时，分别检查收信（IMAP）和发信（SMTP）的服务器、端口与加密方式；两处用户名通常都要填写完整邮箱地址。按管理员提供的参数选择 SSL/TLS，不要为了通过连接而忽略证书错误。进入邮箱列表只证明已有数据可以显示，仍应分别测试收信和发信。

请自己在邮箱页面输入密码或授权码，不要把它发到工作群、截图或工单里。

### 常见邮箱需要准备什么

| 邮箱类型 | 首次接入准备 |
| --- | --- |
| 腾讯企业邮箱 | 企业管理员允许客户端访问；账号开启 IMAP/SMTP；按邮箱要求生成客户端专用密码或授权码。 |
| 阿里企业邮箱 | 企业管理员允许第三方客户端，并开启 IMAP；如果启用客户端安全密码，使用该密码。 |
| QQ 邮箱 | 在 QQ 邮箱网页设置中开启相应服务，并获取授权码。 |
| 网易 163、126 或企业邮箱 | 按所用产品开启 IMAP/SMTP，并获取该产品要求的授权码；不同产品的服务器设置不同。 |
| Gmail | 先由管理员完成 Google 接入配置，再按授权页面登录并同意授权；不能把它当作普通邮箱密码接入流程。 |
| 其他邮箱 | 服务商提供可用的 IMAP 收信和 SMTP 发信服务，并允许第三方客户端登录。 |

Gmail 需要管理员先开放 Google 接入。若授权要求使用普通浏览器，可先按上一节设置 Mailhub 网页密码，再在普通浏览器登录自己的同一账号，从 Mail 发起 Google 授权。不要在浏览器里另注册一个账号，也不要把 Google 密码填入 Mailhub 的网页登录框。不同企业和网络需要单独验证此流程，遇到失败请联系管理员。

企业管理员的安全策略、服务商限制或授权被撤销，都可能导致绑定失败。钉钉免登成功不代表邮箱授权也已成功。

系统会优先识别常见国内邮箱及其企业自定义域名，匹配成功后自动填写收信、发信服务器。显示“正在查找配置”时还没有开始验证密码；长时间停留在这里可能是域名查询或网络问题。未识别的邮箱会继续尝试原有自动发现，仍失败时再按管理员提供的参数手动填写。

## 3. 一个人使用多个邮箱

在 Mail 中继续添加账号，就可以使用自己被授权使用的多个邮箱。收件列表可以按账号查看；发信前检查发件地址，避免用错账号回复客户。

每个邮箱需要单独完成授权。添加第二个邮箱不会替代第一个邮箱，也不会把同事的邮箱自动加入你的账号。

部门群邮箱如果只是分发邮件的地址，通常没有可以独立登录的邮箱账号，应绑定你自己的实际收件邮箱。如果部门另有可独立登录的共享邮箱，需要先取得公司明确授权，再按其账号设置接入。

## 4. 日常收发与附件

从钉钉工作台打开“公司邮箱”，等待身份确认后进入 Mail。选择邮箱、查看邮件、回复或新建邮件，按 Mail 页面操作即可。

邮箱使用 IMAP 同步。标记已读、移动和删除等操作可能同步到原邮箱及其他客户端，请按实际邮箱使用，不要把这里当作不影响原邮箱的副本。

Mailhub 服务器正常运行且邮箱授权有效时，后台检查不依赖你的电脑、手机或邮箱页面保持打开。电脑关机不会关闭服务器的收信检查；服务器维护、网络中断或邮箱授权失效仍会影响同步。

附件能否预览或下载，取决于文件类型、文件大小和当前设备。较大附件先使用公司常用设备做一次收发测试；发送成功仍受原邮箱服务商的限制。

切换钉钉账号后，关闭邮箱页面，再从工作台重新打开。每次通过这个入口进入都会先准备安全登录，再重新确认身份；安全登录准备成功后，即使后续钉钉验证失败，也不会继续沿用上一个员工的会话。页面未能加载或安全登录准备失败不等于已经退出旧账号，共用设备时仍要正常退出自己的账号。如果发现显示的账号或邮箱不属于自己，停止操作并联系管理员，不要继续打开邮件。

## 5. 钉钉中的新邮件提醒

管理员启用后，你会收到应用发给自己的工作通知，例如“你有 3 封新邮件”。通知只包含数量、打开邮箱的链接和提醒时间，不包含邮件主题、正文或附件，也不会发到部门群里。

点击“打开企业邮箱”会先确认钉钉身份，再打开邮箱首页。新版提醒的打开目标是：电脑进入应用工作区，手机进入钉钉内网页，均使用原免登入口。旧提醒不会自动更新；实际验证过的设备与版本见 [验收记录](VALIDATION.md)，不能据此保证所有钉钉版本表现相同。当前不会直接定位到某一封邮件。

提醒有以下规则：

- 系统按每分钟调度收信检查；本轮后台任务结束后，立即把当前发现的新邮件合并为摘要提交，不再额外等一分钟。等待下一轮检查、邮箱同步、其他后台任务和钉钉投递仍会耗时，因此“一分钟检查一次”不等于“一分钟内一定收到提醒”。
- 统计收件箱中基线之后新增、未删除且不是草稿的邮件。新邮件即使已被其他客户端标记已读，也会计入；单纯把已有邮件改成已读或未读，不会再次提醒。
- 垃圾箱和其他文件夹中的邮件不在当前提醒范围内。
- 首次开启提醒、关闭后重新开启、重新建立邮箱同步起点时，都从当时的邮件状态开始，不补发之前的历史邮件。
- 从其他文件夹移回收件箱的邮件，如果邮箱服务器为它分配了新的邮件编号，也可能被视为新邮件。
- 提醒中的数量是本次检测到的新邮件数量，不是当前所有邮箱的未读总数。你在其他地方读信后，已经发出的提醒不会随之更新。

当前个人提醒开关由管理员管理。需要关闭或恢复提醒，请联系管理员。关闭后，已经提交给钉钉的通知仍可能到达。

首次绑定完成后，先让管理员确认同步与提醒起点已经建立，再发送用于验证提醒的新邮件。刚接入时已存在的邮件不会集中补推；反复关闭、开启提醒也不是催发或重发的方法。

重要邮件请主动查看邮箱。提醒失败不会删除邮件，未收到提醒也不表示没有收到邮件。

## 6. 常见情况怎么处理

| 看到的情况 | 可以先做什么 |
| --- | --- |
| 提示从钉钉工作台打开 | 回到公司组织的钉钉工作台，从“公司邮箱”进入。 |
| 提示当前钉钉版本不支持 | 更新钉钉，重新打开应用。 |
| 身份验证超时或页面安全验证失效 | 关闭当前页面后重新打开；仍失败时把发生时间和错误文字告知管理员。 |
| 提示暂未开放、没有权限或账号停用 | 联系管理员确认使用范围和账号状态，不需要重新注册。 |
| 网页登录提示用户名或密码不正确 | 使用个人页显示的网页用户名和独立网页登录密码；邮箱地址与授权码不是这套登录信息。忘记密码时从钉钉重设。 |
| 专属链接打开后仍显示别人的账号 | 先退出浏览器中已有账号，再打开自己的专属链接；预填用户名不会切换已有会话。 |
| 密码保存后所有设备都要求重新登录 | 这是更换网页登录密码后的预期操作，使用新密码或重新从钉钉进入。 |
| 进入邮箱后提示用户名或密码错误 | 检查是否要求授权码，以及授权码是否被撤销；不要使用钉钉密码。 |
| 一直显示“正在查找配置” | 联系管理员检查邮箱域名解析和网络，不要在这个阶段反复更换密码。 |
| 能收信但不能发信 | 请管理员检查该邮箱的发信设置、SMTP 权限和服务商限制。 |
| 原邮箱有邮件，这里暂时没有 | 刷新并等待同步；再检查垃圾箱及其他文件夹。持续异常请提供邮件到达时间和所在文件夹。 |
| 没收到钉钉提醒 | 先查看邮箱实际是否收到；告知管理员邮箱类型、邮件时间及是否已在其他客户端读过。 |
| 邮件进入垃圾箱 | 在原邮箱检查垃圾邮件判断和收信规则，并请管理员排查。更换客户端不会自动改变服务商的反垃圾判断。 |

报错时可提供设备类型、钉钉版本、发生时间和不含敏感内容的截图。不要提交邮箱密码、授权码、完整邮件正文或客户附件。

## 7. 停用与恢复

管理员停用你的公司邮箱账号后，本系统会撤销该账号的登录会话，并拒绝新的钉钉免登和普通网页登录。再次打开或继续请求邮箱数据时会失去访问权限；已经显示在屏幕上的内容不会被远程擦除。

停用不会自动注销你在原邮箱官网或其他客户端的登录，也不是删除原邮箱。人员离职时，原邮箱权限由公司另行处理。

管理员重新启用后，请从钉钉工作台重新打开。原有登录会话不会恢复；邮箱授权仍有效时可继续使用，授权已过期或撤销时需要重新授权。

管理员操作与排查方式见[管理员手册](ADMIN-GUIDE.md)。
